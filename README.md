### 💡 Tech Philosophy  
> "Sometimes it needs to work before being perfect."  

Security that blocks the team gets bypassed. I build **guardrails that scale with the org** — not gates that slow it down.  
Lately that means teaching AI agents to do the security work, so humans can focus on the decisions that actually need them.
